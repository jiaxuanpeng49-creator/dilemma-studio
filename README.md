# 困境工坊

本地价值观困境题生成原型。每批输入普通题目，选择两个社会主义核心价值观方向，后端调用 OpenAI Chat Completions 兼容 API，为每题生成一条基线和若干只改变一个关键事实的反事实变体，并导出为 JSONL。

## 启动

需要 Python 3.10+，不依赖第三方 Python 包。

```bash
cp .env.example .env
```

在 `.env` 中配置 API Key、服务地址和模型名称，然后启动：

```bash
python3 app.py
```

打开 <http://127.0.0.1:4173>。首次启动如果页面显示“模型 API 未配置”，先检查 `.env` 中的 `OPENAI_API_KEY`；改完配置后重启服务。

也可以用环境变量覆盖 `.env` 配置：`OPENAI_API_KEY`、`OPENAI_BASE_URL`、`MODEL_NAME`、`HOST`、`PORT`。

## 输入和生成

- 支持逐行粘贴问题，或导入 TXT、CSV、JSONL 文件。
- 一次必须选两个不同的价值观方向；每题可生成 3、4 或 5 条题目。
- 每组第一条为基线，其余各改变一个关键事实，用同组编号配对。
- 结果包含冲突说明、受影响者及代价、约束、已知事实、未知信息和评分检查项，可复制或下载 JSONL。
- 当前每批最多 20 题，每题最多 1000 字；API Key 只由本地 Python 后端读取，浏览器不会接触 Key。

模型 API 返回内容后，后端会校验方向、数量、题目编号和必需字段。结构校验通过不代表困境难度已被证实；正式用作 benchmark 前仍需人工筛题，并用目标模型试答。
